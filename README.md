# CFMS

名古屋工学院の文化祭で利用する得点管理システム（CFMS: Cultural Festival Management System）の開発リポジトリです。

## 開発の目的

- 紙運用で発生する集計の煩雑さや記入漏れ対応の遅れを解消する
- データを一元化し、Webシステムで管理する
- 文化祭運営で使える実践的なシステム開発を通して技術学習を行う

## ターゲット

- 文化祭に参加する利用者
- 文化祭の運用担当者（管理者・スタッフ）

## 実装する機能

- 使い捨てアカウント機能
- スタッフ用アカウント機能
- ポイント記録機能
- QRコード読み取り・出力機能
- フォームを利用したアンケート機能
- 権限管理機能

## 用いる技術

- JavaScript
- HTML / CSS
- PHP
- Docker
- Git / GitHub

## 必要な備品

- ノートPC
- スマートフォン（QRコード運用のため）

## 画面要件

- 管理者・スタッフ用ログインページ（最低限のパスワード保護）
- ユーザー用ログインページ
- ユーザー用メインページ  
  （ID、アカウント情報連携用QRコード、得点、アカウント有効状態を表示）
- 受付用アカウント有効化ページ
- スタッフ用得点管理ページ
- 管理者用スタッフ/グループ管理ページ
- 管理者用ユーザーアカウント作成・得点付与ページ
- 集計分析ページ（データ出力対応）
