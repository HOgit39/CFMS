データ定義書メモ


Users(利用者)
------------------
id PK
name
is_active
finished_at(アカウントの終了時刻)
created_at


Staff(管理者とスタッフ)
------------------
id PK
name
password(ハッシュ化する)
role(列挙型で作成)


Stores(店)
------------------
id PK
name


Scores
------------------
id PK（履歴の主キー）
Users_id FK（ポイントの持ち主）
Staff_id FK (Staffは複数形無し)
(そのポイントを記録した担当者のID。ユーザーの不正監視を目的とする)
score
Stores_id FK
(どの店のポイントかを記録）
created_at
(時間を記録することで日ごとの集計が可能になる）
